## All Mappings

| Action | Right Hand | Left Hand | Conditions |
|--------|:----------:|:---------:|------------|
| Previous card | ← | A | Focused card; browses within its zone, including Discard |
| Next card | → | D | Focused card; browses within its zone, including Discard |
| Move to table | ↑ | W | Multiplayer, owned card |
| Move to hand | ↓ | S | Multiplayer, owned card |
| Yoink (claim card into Hand) | ↓ | S | Unowned Pile card, or any Discard card in multiplayer |
| Play to pile | Space | Space | Card focused, owned |
| Pick up from deck | Space | Space | No card focused |
| Create card | | C | No card focused |
| Like card | | G | Card focused |
| Enter send mode | Enter | F | Multiplayer, owned card |
| Return to deck | Backspace | R | Multiplayer, owned card |
| Discard | Delete | X | Owned card |

| Box | | B | Multiplayer, focused card you own |
| Unfocus card | Escape | Q | |
| Cycle zones | Tab | Tab | Hand, Table, and Pile only; Shift+Tab reverses the cycle. Discard stays outside it. |
